Paws 三端完整设计稿（Phone · Pad 触屏档 · PC 指针档）

这是按 nsh-gallery-ui 规范校正后的三端完整目标设计稿，覆盖全部 14 类页面与状态：① 尺度按输入方式分两档——Gallery 对触屏与桌面指针各定义一档（platform.desktop 判定），Phone 与 Pad 用触屏档（15 pt 正文、40 pt 按钮、46 pt 输入框、42×24 pt 开关、22 pt 单选/复选、16 pt 卡片圆角），PC 用指针档（13 pt 正文、28 pt 按钮与输入框、28×16 pt 开关、16 pt 单选/复选、10 pt 卡片圆角）；三端仅在壳层导航（底栏 / 64 pt 图标轨 / 232 pt 侧栏）与多栏布局上随视口自适应；② 首页策略组默认全展开——全部策略组随整页统一滚动，没有“查看策略组”入口；③ 连接与请求、日志对齐 NSH Gallery——统一采用 Segmented + Picker 组合筛选，补齐“请求历史”独立画面与三端一致的详情面板/检查器。

当前真机问题复盘

首页与核心页面的问题和修正标准

序号与下方手机画面上的红色标注一一对应；本次已按最新真机反馈同步修正“首页策略组全展开”，并把尺度校正为 NSH Gallery 的触屏 / 指针两档。

01

连接动作出现三次

电源图标块、"连接"按钮和悬浮按钮都能连接，真正的按钮反而很小，而且靠左。修正：首页只保留连接卡片里的一个全宽按钮。只有当连接卡片滚出屏幕时，才显示悬浮按钮。

02

按钮样式不一致

"代理节点"带阴影，"当前分组"不带。修正：这两个入口都不再做成按钮，并入"当前节点"那一行，点按后进入代理节点页。

03

速率区缺少分组

标题和"当前没有实时数据"挤在同一行。修正：上传和下载做成两格数值，单位单独标出。未连接时数值显示为 0，下方用说明文字解释原因。

04

策略组嵌套滚动或被折叠收拢

早期套了内层滚动框，后续截断为 3 组并加“查看全部策略组”破坏了直达性。修正：首页「策略组」默认完整平铺全部策略组，作为整页内容统一滚动，绝不默认收拢，也不设“查看策略组”操作。

05

悬浮按钮压住内容

悬浮按钮压在"69 个节点"上。修正：同 01。悬浮按钮出现时，页面底部要留出等高的空白。

06

表面层级与字号尺度不一致

真机上小一号字号显得局促，卡片描边与控件尺寸不统一。修正：Phone / Pad 采用 NSH Gallery 触屏档（15 pt 正文、40 pt 按钮、46 pt 输入框、16 pt sectionSurface 无阴影卡片），PC 采用指针档（13 pt 正文、28 pt 按钮与输入框、10 pt 卡片）；Phone 左右边距 16 pt。

订阅的完整流程

从没有订阅开始：添加、更新失败、查看详情、删除。更新失败只在对应行和横幅里说明，其他订阅仍可操作。

Phone · 流量与连接

流量、连接与请求（严格对齐 NSH Gallery）

「连接与请求」统一收口原分散入口，顶部分段在「活动连接」与「请求历史」间就地切换；筛选全面采用 Gallery 凹陷轨道 Segmented 与 Picker（移除异质的散装筛选胶囊），列表行保持双栏清爽层级，点按打开 Gallery 底部详情面板。

Phone · 资源与日志

资源与规则、日志（严格对齐 NSH Gallery）

三端日志统一采用「当前日志 / 历史归档」分段与单行五级 Segmented（全部 / 信息 / 警告 / 错误 / 调试）；每条日志使用 Gallery sectionSurface 列表行与语义色徽章，点按打开底部详情面板。

Phone · 设置与工具

设置入口、诊断、备份

设置是第四个底栏入口，也是网络、工具和偏好的统一入口。「网络」分组明确收口为「连接与请求」「资源与规则」「日志」三项，不重复拆分连接与请求。

Phone · 转换、外观、YAML

订阅转换、外观与关于、YAML 编辑

转换设置离开时自动保存，生成结果只保留在本次会话；输入变化后旧结果立刻标记失效。YAML 编辑是整页，离开时守护未保存的修改。

状态 · 全端共用

连接状态与页面状态

连接只有在路由验证完成后才显示"已连接"。命令收到回应不等于已生效。每个页面的加载、空、失败、无结果状态都有设计，不留空白。

组件状态 · 回应你的问题

Tab 与列表行的五种状态

手机底部 Tab 不再用整块底色表示选中：选中项是品牌色的加粗图标和更深的加粗文字，图标和文字两处都变，不只靠颜色。按下时，图标后面出现一个短暂的小椭圆，松手即消失，所以按下一个已选中的 Tab 也看得到反馈。焦点环是单独的一圈，可与选中同时出现。列表行和按钮的状态不变。

流程与设计边界

主要任务的返回与提交规则

首页→添加订阅→启用订阅→连接→选节点→确认生效→返回首页
任意草稿→返回 / 切换目的地→继续编辑 或 放弃修改→只放弃未提交部分
已提交→状态读取失败→重新读取→不重新提交原命令

菜单先关闭，再开表单。Escape / 系统返回先关闭顶层弹层，焦点回触发点。两种恢复语义不同，按钮文案也不同：从备份文件或 WebDAV 恢复，是新建配置副本，保留现有订阅，按钮写"恢复为新配置"；恢复某个订阅的上次备份，会覆盖该订阅，按钮保留现有的"恢复并覆盖"，并写出订阅名称。自动策略组若实际支持固定节点，使用明确的“固定此节点 / 恢复自动选择”，不隐去已有能力。

主题令牌与 Gallery 的已知差异

Paws 主题（ui/nsh/theme.json）有意与 Gallery 不同：新增 stop-fill、on-stop、brand-fill；圆角令牌 radius-control 10（Gallery 7）、radius 12（Gallery 10）、radius-card 16（Gallery 12）；背景、卡片等色值也不同。控件尺寸按上表对齐，主题色值和圆角令牌保持 Paws 的取值。
